# Ticket Template

Use this template when publishing a tracer-bullet ticket.

```markdown
## Parent

<reference to the spec or source issue>

## What to build

<the end-to-end behaviour this ticket makes work>

## Metadata

- Labels: `ready-for-agent` plus justified inherited labels
- Milestone: <phase milestone or none>
- Project: <project board or none>
- Fields: Work Type = Ticket; Repo Scope = <scope>; Phase = Ready for agent; Priority = <priority>; Risk = <risk>; Sprint = <sprint or none>; Release Train = <train or none>

## Acceptance criteria

- [ ] <observable behavior, contract, or state transition>
- [ ] <edge case or failure mode>

## Validation

- <command or observable check that proves the criteria>

## Blocked by

- <blocking ticket references, or "None — can start immediately">

## Notes

- <scope boundary, risk, or implementation hint>
```
